# Human reference transcripts

Ground truth for measuring the pipeline. Scored by `compare_reference.py`:

```
python compare_reference.py reference/2024-10-15_kP4iRYobyr0.human.txt
```

Naming: `<meeting date>_<video id>.human.txt`.

## Why these exist

Nothing else in this project measures whether the archive names the right
speaker. Changes that touched attribution — the resolved-name paragraph
grouping, the bare-surname rule conversion, the speaker provenance guards —
were each checked by hand on a sample, because there was no metric. These
files are the metric.

## `2024-10-15_kP4iRYobyr0.human.txt`

City Council Committee of the Whole, 2024-10-15 (4h42m). Produced by the
project owner **before** the pipeline existed, by editing YouTube's
auto-captions. Read the limits before trusting a number derived from it:

- **Not verbatim.** The document's own header: *"Captions auto-generated by
  youtube and edited for clarity. Edits remove filler words and add headings
  to make it easier to skim."* Deleted fillers mean this **cannot** serve as a
  word-error-rate benchmark — scoring against it would penalise the pipeline
  for transcribing speech that the reference intentionally removed.
- **Only the first ~220 lines are human-edited.** Editing stops at line 297;
  after that the file is raw, uncorrected YouTube auto-captions in YouTube's
  own layout (a bare `H:MM:SS` line above each caption, lowercase, errors
  intact — "councelor", "Mr cler"). That region carries no speaker labels, so
  the `[Music]` and `[Applause]` tags there are YouTube's sound tags, not
  turns. `read_reference()` stops at the first raw timestamp line.
- **Partial coverage even in the edited region**: 3,554 reference words
  against the pipeline's 46,627. Much of it is narration ("Councilor
  Scarpelli asked that the administration and Council on Aging do outreach")
  rather than quotation. The two documents are *not* a parallel text.
- **It has its own errors.** Its labels read `Lemming` and `Castanetti` where
  its own header and the archive read `Leming` and `Castagnetti`; it keeps
  YouTube's "please call the role" where the pipeline correctly has "roll".
  A reference is evidence, not an oracle — disagreements are adjudicated, not
  assumed against the pipeline.

What it **is** good for: **speaker attribution**, because the labels were
assigned by a human who listened; and **proper nouns**, because a second ASR
plus a human editor caught names independently.

## How scoring works

The reference has no per-turn timestamps, so the documents are aligned by
text: 4-grams unique in *both* become anchors, and the longest increasing
subsequence of those gives a monotone chain. A turn is scored by the
**majority** pipeline speaker across the anchors inside it — not the first
one, which turned a 4-word boundary slip into an apparent 135-word error.
Turns with no anchor (`"Present."` is too short to contain a unique 4-gram)
are reported unmatched rather than guessed at: a wrong alignment scores a
*correct* attribution as an error, the one failure mode that would make this
metric worse than no metric.
